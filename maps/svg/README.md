# 2D map overlay

These SVG maps are from the Escape from Tarkov SVG Maps Project (https://github.com/the-hideout/tarkov-dev-svg-maps),
by its contributors, licensed CC BY-NC-SA 4.0 (LICENSE.md). They are used unchanged; the atlas page hides the
floor layers you aren't looking at and paints the map onto the 3D ground and floors.
